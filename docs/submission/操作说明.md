# 诗境漫游 · 操作说明

## 一句话
戴上头显，走到诗人站过的位置，看他看的山，听他听的水。第一首样板《望庐山瀑布》。

## 启动
1. 安装 `app-debug.apk`（Android / PICO OS 6，包名 `com.example.demo`）
2. 从应用列表启动「诗境漫游」，进入书房态（一张宣纸卷轴悬在空间中）

## 书房态：一卷三栏
- 左栏：诗题「望庐山瀑布」、唐 · 李白、朱砂「诗境」印
- 中栏：四句正文，**点任意一句**，该句变朱砂红并出现红色界格
- 右栏：注释与赏析，随选中句放大加粗；底部是意象标签「山 水 烟 银河」

## 三枚印章
- **注释**：展开独立注释窗（多窗口，可与主卷轴并排看）
- **赏析**：展开独立赏析窗
- **入诗**：进入入画态（Full Space Stage），山水铺满视野

## 入画态
- 画面为青绿山水：紫云、远山、主瀑布、松影、水潭，岩台上有白衣文人背影
- 场景分两层：远景在 10 米处、前景（松树 / 崖台）在 6.2 米处，**向前或向侧走会看到前后景错位**，产生真实视差
- 目前入画态为静态观赏；四段光照（晨 → 上午 → 正午 → 夜）代码已就位，随诗句推进切换

## 输入方式（模拟器已实测）
模拟器窗口**底部工具条**从左到右：交互 / 控制下拉 / 垂直平移 / 水平平移 / 俯仰 / 转视角 / 复位。

- **转视角**：先点底部倒数第二个按钮（转视角），再在画面里**按住鼠标左键拖动** —— 左右转身、上下抬头低头
- **平移（走动）**：点「水平平移」按钮后左右拖动；「垂直平移」用来升降
- **复位**：底部最右侧按钮，回到默认朝向（走进画里以后用这个退回来）
- 头显上：眼动注视 + 捏合（主交互），手柄扳机选中、摇杆移动

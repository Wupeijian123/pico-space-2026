# 诗境漫游 · 依赖与素材说明

## 运行环境
- 目标设备：PICO OS 6 空间应用（Android 运行时）
- minSdk / targetSdk：见 `app/build.gradle.kts`
- 语言：Kotlin + Jetpack Compose（PICO Spatial UI）

## 关键技术依赖
| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| PICO Spatial SDK（core / ui / platform / sense / tracking） | 6.2.8 | 空间容器、Entity 场景、SpatialView、窗口与 Stage |
| Kotlin | 见 `gradle/libs.versions.toml` | 应用与场景代码 |
| AndroidX Compose（随 PICO Spatial SDK 提供） | — | 窗口内 UI |
| PICO Emulator | 6.2.1 | 本地调试与录屏 |

## 构建
```bash
cd E:/pico/projects/demo
export JAVA_HOME=E:/pico/jdk/jdk-21.0.13+9
export ANDROID_SDK_ROOT=E:/pico/android-sdk
./gradlew assembleDebug
```
产物：`app/build/outputs/apk/debug/app-debug.apk`

# 诗境漫游 · 作品信息与提交清单

## 作品信息
- 作品名：诗境漫游（Poemscape）
- 赛道：PICO Space Program 2026 · PICO Spatial 空间应用创作
- 技术栈：Kotlin + PICO Spatial SDK 6.2.8（Spatial UI / Entity 场景 / SpatialView / Stage）
- 分类：文化教育 · 内容消费
- 一句话简介：戴上头显，走到诗人站过的位置，看他看的山，听他听的水。
- 应用简介：把古诗词鉴赏从"读注释"变成"进画里"。书房态是一卷三栏的批注本，点句高亮、随读随注；入画态把《望庐山瀑布》的青绿山水铺成真实尺度的空间画面，人在岩台之上，瀑布在眼前落下，走到侧面能看到前后景错位。第一首样板为《望庐山瀑布》，架构可扩展到更多诗词。
- 内容标签：古诗词、国风、青绿山水、空间阅读
- 特性标签：多窗口、Full Space Stage、视差景深、眼手交互

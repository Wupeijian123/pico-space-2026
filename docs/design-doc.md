# 诗境漫游 · 设计框架 v1

PICO Space Program 2026 · Spatial 空间应用创作赛道

## 一句话定位

戴上头显，走到诗人站过的位置，看他看的山，听他听的水。

面向诗词爱好者，碎片时间漫游鉴赏，可反复使用。

## 形态：双态

- 书房态（Shared Space）：多窗口并存，读、注、赏、找、藏
- 入画态（Full Space / Stage）：空间漫成山水，站在诗人机位读这一首
- 两个态之间用一次"入诗"转场连接，转场本身是核心体验

## 五个核心动作

1. 展卷：卷轴横向展开，诗题与正文浮现，配纸张摩擦声
2. 入诗：注视印章捏合，空间从卷轴漫开成山水，镜头推到诗人站位，浮出"你在此处"
3. 品鉴：注视焦点物（山/水/月/舟），注释与赏析浮出
4. 留印：读完盖一枚朱砂印，有落印声与轻微震动，入收藏册
5. 出画：卷轴合拢，退回书房态

## 书房态窗口清单

| 窗口 | 尺寸 (dp) | 内容 | 主要交互 |
|---|---|---|---|
| 主卷轴窗 | 1200×560 | 诗题、正文、作者、朝代 | 展卷/合卷、切诗 |
| 注释窗 | 720×640 | 逐句注释、字词训诂 | 随选中句联动 |
| 赏析窗 | 720×640 | 历代评点、意象标签 | 标签可点，跳检索 |
| 意象检索窗 | 900×560 | 山/水/月/舟/雪 五枚印 | 点印出相关诗 |
| 收藏册窗 | 1000×700 | 已盖章的诗，按意象分组 | 翻开、重读 |

要求：任意时刻至少 2–3 个窗口并存，可拖动、可关、可归位（多窗口是评分硬指标）。

## 入画态（样板：望庐山瀑布）

- 山水三层剪影：远山淡、中山中、近山浓，随视线位移做视差
- 天光：垂直渐变，晨雾用半透明平层叠
- 焦点物：瀑布（多条半透明面做下落，底部水雾粒子）
- 诗句层：五言句随视角浮出，注视可停留细读
- 音场：瀑布声锚定在瀑布位置，站在山脚时声从下方来

## 交互映射（三路输入都必须走通）

| 动作 | 眼手 | 手柄 | 模拟器（鼠标键盘） |
|---|---|---|---|
| 注视选中 | 注视 + 捏合 | 扳机 | 鼠标左键 |
| 展卷 / 合卷 | 捏住卷边拖动 | 摇杆 + 扳机 | 拖拽 |
| 入诗 / 出画 | 注视印章 + 捏合 | A 键 | 界面按钮 |
| 环顾 / 回望 | 转身 / 手势 | 摇杆 | 按住右键拖动 |
| 盖印 | 捏合按印 | 扳机 | 左键 |

## 技术骨架

- 容器：多 Window（planar）为书房态；Stage 为入画态
- 3D：Entity + ModelComponent；山为三层透明平面，瀑布为动画材质
- 音频：空间音频源锚定瀑布坐标
- 状态：AppState（书房 / 入画 / 收藏）+ 当前诗 id + 收藏集合（本地持久化）
- 数据：每首诗一个 JSON —— 标题、作者、句子、逐句注释、赏析、意象标签、机位参数（站位、朝向、焦点物）

## 视觉与素材规范

- 主色：墨黑 #1C1B19、宣纸 #F2EADA、朱砂 #A8322D、石青 #4A6B7C
- 字体：霞鹜文楷（LXGW WenKai，OFL）或思源宋体；不得使用商业字体
- 音效：纸声、墨滴、落印、木器碰撞，需 CC0 或自制
- 纹理：宣纸噪点程序生成，避免大图占内存
